🤖 AI Interviewer

An AI-powered mock interview project built using Python, AutoGen and LLMs.

This project uses 3 AI agents working together to create a complete interview experience:

🎤 Interviewer – asks interview questions and conducts the interview.
👨‍💻 Interviewee – answers the questions like a real candidate.
🧑‍🏫 Career Coach – reviews the answers, gives feedback, and suggests better ways to answer.
🔄 How it works
Interviewer → Interviewee → Career Coach → Feedback

The main goal is to help candidates practice interviews, improve their answers, and get instant AI-powered feedback.

🛠️ Tech Used

Python | AutoGen | LLMs | OpenAI/Gemini API | AsyncIO
